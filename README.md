A late-night ramen shop cooking game. Tickets come in on the rail — grab a bowl, pour the right broth, time the perfect noodle pull, add the toppings, and ring the bell at the serve window before the customer walks out. Fast serves and perfect pulls pay more, combos build across the 180-second shift, and the rush only gets busier.

Play it with keyboard (WASD / arrows + E) or mouse (click a station to walk there). No network needed — everything runs from static files, with sounds synthesized in the browser.

## Run it

Open `game/index.html` in a desktop browser, or serve it locally:

```sh
node serve.ts
```

then open http://localhost:8080. To build the submission output:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
